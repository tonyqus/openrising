## “伦敦每月可存约9,000元”怎样成立？

此前讨论提出过这个可能性。为了让读者看清前提，下面是重新构造的教学情景，不是实际报价、当前汇率或经过确认的生活账单：

| 项目 | 每月金额（GBP） | 性质 |
| --- | ---: | --- |
| 税后收入 | 4,088 | 使用上表历史讨论值 |
| 房租 | 1,700 | 使用上表历史讨论值 |
| 食品 | 350 | 教学假设 |
| 交通 | 200 | 教学假设 |
| 水电、通信 | 200 | 教学假设 |
| 其他必要及杂项支出 | 250 | 教学假设 |
| 年度费用月均分摊 | 388 | 教学假设 |
| 总支出 | 3,088 | 上述支出合计 |
| 月度结余 | 1,000 | 收入减总支出 |

若**仅为演示**设£1 = ¥9，£1,000对应¥9,000。该汇率不是当前报价。

在相同演示汇率下：

| 情景 | 税后收入（GBP） | 总支出（GBP） | 月结余（GBP） | 折合CNY |
| --- | ---: | ---: | ---: | ---: |
| 基准假设 | 4,088 | 3,088 | 1,000 | 9,000 |
| 收入下降20% | 3,270.4 | 3,088 | 182.4 | 1,641.6 |
| 支出增加20% | 4,088 | 3,705.6 | 382.4 | 3,441.6 |
| 两者同时发生 | 3,270.4 | 3,705.6 | -435.2 | -3,916.8 |

因此，“约9,000元”是特定收入、住房、生活方式和汇率下的情景结果。它不能证明伦敦普遍比上海更容易攒钱。上海也应以可获得的工资和完整预算计算后再比较。

## 来源与复核方法

- [Numbeo：上海](https://www.numbeo.com/cost-of-living/in/Shanghai)与[伦敦](https://www.numbeo.com/cost-of-living/in/London)：动态页面。记录访问日期、币种、住房类型与数据样本说明；本章历史值尚缺对应快照。
- [Expatistan](https://www.expatistan.com/cost-of-living)：核实是否包含住房、单人还是家庭、使用什么消费篮子，避免与其他平台拼接成貌似精确的结论。
- [数字游民分析参考项目](https://github.com/Aventardo7777/digital-nomad-data-analysis)：本次已阅读README，其明确描述课程作业与模拟采集。用作学习参考，不认证其中图表为实测市场结论。
- 雇主岗位与真实房源：个人决策需要重新采集。保留URL、日期、原币种、适用人群、经验和地点限制。
